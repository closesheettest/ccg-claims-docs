How to Get It Signed

Two steps. One question. Follow the arrows. 👇
1

Fill in the form

Type the homeowner's info. Get all of it right — the code is sent to the phone & email you type in.

✏️ Name · 📱 Cell phone · ✉️ Email · 🏠 Address
2

Ask yourself ONE question

👉 “Am I standing right next to the homeowner?”
🤝 YES — I'm at the door with them
Tap this button:
Sign now — I'm with them
  1. They open the link on their phone.
  2. A 6-digit code pops up on YOUR screen.
  3. Read the code out loud to them.
  4. They type it in and sign. ✅
⚠️ The code is on YOUR screen — not theirs. Stay on that screen!
📞 NO — on the phone / not here
Tap this button:
Send for signing — remote
  1. They get a text AND an email.
  2. It has the link and the 6-digit code.
  3. They open it, type the code, and sign. ✅
  4. You do nothing else. 🎉
👍 The code goes to THEM. You never need to see it.
The Golden Rule — remember only this
🤝 WITH them (at the door) → Sign now
📞 NOT with them (on the phone) → Send for signing — remote

🆘 “It wants a 6-digit code and they don't have one!”

Nine times out of ten, you tapped “Sign now” but you're NOT standing with them.

Fix it in 3 taps:

  1. Tap “🗑 Void old request & start fresh.”
  2. Fill the form in again.
  3. This time tap “Send for signing — remote.”

Now the code goes straight to their phone & email — and they can sign on their own. Done.
